Evolutionary Training

Every agent has its own isolated goal and obstacle; collecting a goal relocates only that agent's goal. When any agent collects five goals, the entire population resets together from that winner: one unchanged elite is kept and the remaining agents are mutated descendants with fresh independent environments. If nobody reaches five goals within two minutes, the agent with the most goals, best measured progress, and then most remaining energy becomes the next parent. After collecting one goal, an agent cannot be eliminated by running out of energy.

Memory & Model

Agent Five stores up to 192 state memories and 48 short episodic sequences. Similar situations can recall useful actions, while PPO learns from complete action/reward trajectories. Descendants inherit the winner's policy, value network, and memories.
